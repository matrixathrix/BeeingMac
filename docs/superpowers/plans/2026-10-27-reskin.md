# Night bloom reskin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Material You's wallpaper colours and the Baloo/Fredoka fonts with Beeing's own "Night bloom" light/dark palette, Plus Jakarta Sans, a brand band on every tab, shared card/chip/button styles and a Swiggy-style nav bar, uniformly across the app.

**Architecture:** Almost every colour already flows through `MaterialTheme.colorScheme` (172 references), so a fixed Beeing light/dark `ColorScheme` reskins most of the app at once. Values a `ColorScheme` can't hold (band gradient, accent-as-text) live in a small `BeeExtras` CompositionLocal. Shared composables (`BrandBand`, `BeeCard` defaults, the nav bar) carry the rest, and each tab then adopts them.

**Tech Stack:** Kotlin, Jetpack Compose Material 3 (BOM), JUnit 4 for local unit tests, adb for on-device verification.

**Spec:** `docs/superpowers/specs/2026-10-27-reskin-design.md`

## Global Constraints

- No dynamic colour anywhere; follow `isSystemInDarkTheme()`.
- Band gradient: light `#4A1D4F → #2E0F33`, dark `#2C1030 → #1C0920`, ~160°; bottom corners 26dp; white text on it.
- Accent `primary = #F5A623`, `onPrimary = #2E0F33`; accent-as-text `#C7820A` light / `#F7B733` dark.
- Page `#F7F5F2` / `#110E12`; card `#FFFFFF` / `#1D1A1F`; muted fill `#F1EEEA` / `#2A2630`; text `#1B1A1C` / `#ECE7EA`; secondary text `#76717A` / `#9C969B`; hairline `#EEE9E4` / `#2A2630`.
- Font: Plus Jakarta Sans, static 400/500/600/700/800, bundled in `res/font/`. No Baloo or Fredoka left in the code or the APK.
- Cards: `surface` fill, 20dp radius, soft shadow in light mode only. No blur/RenderEffect anywhere.
- No layout or behaviour changes beyond moving header content into bands. Score bands keep red 1-4 / amber 5-7 / green 8-10 and keep their digits.
- Save (rating) and Lock (caught-up) stay pinned above the nav bar; tags remain the only region that absorbs a height shortfall.
- Build: `JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"`, `.\gradlew.bat assembleDebug`, then `adb install -r app\build\outputs\apk\debug\app-debug.apk`. adb is `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`.

## Review Focus

1. **Short screens:** with the display shrunk (`adb shell wm size 1080x1900`), the Now tab's Save and Lock buttons stay fully visible and tappable, and the tags scroll instead. Owned by Task 4's device check.
2. **Large font scale:** at `adb shell settings put system font_scale 1.3`, band text doesn't clip and Save is still on screen. Owned by Task 4's device check.
3. **Dark mode switch while the app is open** (`adb shell cmd uimode night yes|no`): every tab, sheet and dialog flips with no leftover light surface or white flash. Owned by Task 7's sweep.
4. **Contrast:** honey accent with white text would be unreadable, and secondary text can fall below legibility. The palette contrast unit tests in Task 1 pin this.
5. **Status bar over the band:** status-bar icons must stay light on the band in *light* mode too, and nothing must flash when paging between tabs. Owned by Task 3's device check.
