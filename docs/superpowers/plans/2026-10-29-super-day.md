# Super Day Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Name the 12-counted-hour Master day a "Super day", invite the user to it right after the ring closes (only when realistic), celebrate it (also after midnight), and mark it on the rings, calendar, journal and History.

**Architecture:** The engine (`StreakRules.kt`) exposes a per-day tally for yesterday and today on `StreakState`. Celebration triggers become pure, **day-keyed** comparisons of two snapshots. A new pure `SuperDay.kt` holds reachability, the invite rule, the passive cue and the Save-label hint. New screens go in `SuperDayScreens.kt`, and the shared outer-lap drawing goes in `ui/SuperLap.kt`.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), JUnit 4 JVM tests, SharedPreferences `"b"`.

**Spec:** `docs/superpowers/specs/2026-10-29-super-day-design.md`

## Global Constraints

- `SUPER_DAY_HOURS = 12`, `SAVER_EARN_HOURS = SUPER_DAY_HOURS`, `SUPER_DAY_SLACK = 1`: all in `StreakRules.kt`.
- Super day = mode at day end is Master and `countedHours >= 12`. Backdated (`RECLAIM_TAG`) hours never count. Beginner days never qualify.
- No change to any `DayOutcome`, saver or streak number. Existing `StreakRulesTest` outcome and streak assertions must pass unchanged.
- Existing `StreakEvent` ids never change. `SUPER_DAY` stays out of `WARNING_TYPES` and `ALERT_TYPES`.
- The only new stored value is `"super_invite_shown_day"` (Long, the day's start millis) in prefs `"b"`. It is not exported in the CSV.
- Light gold `SuperGold = Color(0xFFFFD54F)` (new in `ui/theme/Color.kt`) for the outer lap and Super day accents. The inner ring stays `HoneyGold`. The field is `BandBottomLight`.
- Copy, verbatim: "Make it a Super day" · "N more hours tonight. A Super day earns a streak saver." · at the cap: "All 5 streak savers are already saved up." · button "Let's go" · overline "DAY COMPLETE" / "SUPER DAY" · "Super day" · "Streak saver earned. N of 5 saved up." / "All 5 streak savers saved up." · button "Keep going" · late: "Yesterday's ring closed", "Yesterday was a Super day" · Save hint " · finishes your Super day" (and " · closes yesterday's ring") · caption "N more for a Super day".
- The invite has exactly **one** button. No haptic on the invite. With system animations off, show end states.
- Read animated values only in `graphicsLayer {}` / draw / `layout {}` lambdas, never in composition.
- Build: `JAVA_HOME="C:\\Program Files\\Android\\Android Studio\\jbr" ./gradlew <task>` from the repo root (Git Bash).
- The owner tests on their own device. Verify by build and install, then hand over a device test list.

## Review Focus

1. **App left open across midnight with no save.** At 00:00 the snapshots shift days, and nothing must celebrate. Task 2 test `midnight_rollover_without_a_save_never_fires`.
2. **Delete then Undo of the 8th hour.** Beat 1 replays (existing behaviour) but the invite must not. Task 6 test `invite_flag_blocks_a_second_invite_the_same_day`.
3. **Silent hours starting mid-hour (22:30).** The reminder moment, at the hour's end, decides. Task 3 test `silent_start_mid_hour_drops_the_hour_whose_end_is_silent`.
4. **DST days (23 or 25 hours).** Reachability must iterate the day's real hours. Task 3 test `dst_spring_forward_day_has_23_candidate_hours`.
5. **Super day at the saver cap.** The screen fires with no saver line, and History doesn't claim a saver. Task 2 test `twelfth_hour_at_cap_fires_super_day_without_saver`, Task 8 test `super_day_log_detail_at_cap`.

### Task 3: `SuperDay.kt` — reachability, invite, cue, late hint (pure)

**Files:**
- Create: `app/src/main/java/com/example/beeing/SuperDay.kt`
- Test: `app/src/test/java/com/example/beeing/SuperDayTest.kt`

**Interfaces:**
- Consumes: `DayTally`, `NotificationPrefs`, `inSilentHours`, `PauseMode`, `SUPER_DAY_HOURS`, `SUPER_DAY_SLACK`.
- Produces:
  - `fun reachableHours(dayStartMs: Long, countedStarts: Collection<Long>, prefs: NotificationPrefs, nowMs: Long): Int`. Walk the day's real clock hours with `Calendar.add(HOUR_OF_DAY, 1)` until the next day's start (this handles DST). Skip counted hours. Let `cur` be the start of `nowMs`'s clock hour. Hours at `cur-1h` and `cur-2h` are **always** counted when they're in this day (ratable now). A hour with start `>= cur` counts unless its end (`start + 1h`) is `inSilentHours` or `prefs.pauseMode == OFF && prefs.pauseUntilMs > end`. Every other hour is past and is skipped. `remindersOn` is ignored on purpose (spec).
  - `data class SuperInvite(val hoursNeeded: Int, val savers: Int)` (at the cap when `savers >= SAVER_CAP`)
  - `fun superInviteFor(day: DayTally, savers: Int, reachable: Int): SuperInvite?`: null when `day.beginner` or `countedHours >= 12`. Otherwise `needed = 12 - countedHours`, and the result is non-null iff `reachable >= needed + SUPER_DAY_SLACK`.
  - `fun superCueFor(day: DayTally?, reachable: Int): Int?`: hours left when the day is Master, `goal <= countedHours < 12` and `reachable >= needed` (no slack). Otherwise null.
  - `fun lateHourHint(hourStartMs: Long, days: List<DayTally>): String?`: when `hourStartMs` falls in a non-today, non-beginner tally and isn't counted yet, return `" · finishes your Super day"` if `countedHours == 11`, `" · closes yesterday's ring"` if `countedHours == goal - 1`, else null.
